Hintergrundbilder für das Standard-Theme (RGB-Style)
======================================================

Lade hier beliebig viele Bilder hoch (JPG, JPEG, PNG oder WEBP) — unbearbeitet,
so wie sie sind. Bei jedem Seitenaufruf wird zufällig eines davon als
Hintergrund gewählt. Die Website kümmert sich automatisch um Abdunkeln und
Rand-Verlauf ins Schwarze, du musst die Bilder also nicht selbst bearbeiten.

Diese Datei (README.txt) kannst du drin lassen, sie wird ignoriert.
Ist der Ordner leer, wird kein Hintergrundbild angezeigt.
