Hintergrundbild für das Sommer-Theme
======================================

Lade hier genau EIN Bild hoch (JPG, JPEG, PNG oder WEBP) — unbearbeitet. Es
wird immer verwendet und NICHT zufällig gewechselt (anders als beim
Standard-Theme). Liegen mehrere Dateien hier, wird die alphabetisch erste
genommen. Abdunkeln und Rand-Verlauf übernimmt die Website automatisch.

Diese Datei (README.txt) kannst du drin lassen, sie wird ignoriert.
Ist der Ordner leer, wird kein Hintergrundbild angezeigt (nur das
bestehende Wellen-/Sonnen-Muster).
